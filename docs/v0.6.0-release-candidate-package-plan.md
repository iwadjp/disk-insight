# v0.6.0 Release Candidate Package Plan

This document defines the structure, build procedure, and pre-publish checks for
the v0.6.0 release candidate package.

No package is built in this phase (v0.6.0-I).
The package build script is planned for v0.6.0-J.

---

## 1. Purpose

This package is the candidate artifact for a future GitHub Release.

Goals:
- Confirm artifact structure before publishing
- Bundle README / LICENSE / SECURITY-OVERVIEW / BUILD-INFO / SHA256 together
- Provide a reproducible artifact for dogfooding and review
- Clearly document that the binary is unsigned
- Defer the GitHub push / tag / release decision to a later phase

---

## 2. Package name

```
disk-insight-v0.6.0-windows-x64.zip
```

The zip must contain a single root folder:

```
disk-insight-v0.6.0-windows-x64\
```

Reason: zip extraction does not scatter files; version and platform are visible
from the archive name alone.

---

## 3. Package contents

Minimum required:

```
disk-insight-v0.6.0-windows-x64\
  disk-insight-ui.exe
  README.md
  LICENSE
  SECURITY-OVERVIEW.md
  BUILD-INFO.txt
  SHA256SUMS.txt
```

Optional (add only if it does not significantly increase archive size):

```
  docs\
    company-pc-dogfooding-checklist.md
```

Start with the minimum structure. Add optional files only after the minimum
package has been verified.

## 5. BUILD-INFO.txt format

```
Project           : disk-insight
Version           : 0.6.0
Commit            : <full hash>
Commit short      : <short hash>
Branch            : <branch>
Build time        : <local time>
Signed            : NO
GitHub Release    : NO
Safety model      : Normal + Advanced
Company-safe UI   : removed in v0.5.18-C
Network           : none
Telemetry         : none
Updater           : none
TREE_FOCUS_DEBUG  : false
PERF_LOG          : false
PERF_TREE         : false
```

Encoding notes:
- ASCII-safe only; no em dashes, smart quotes, or non-ASCII characters
- Must render correctly in Notepad on any Windows locale

---

## 6. SHA256SUMS.txt format

```
<sha256>  disk-insight-ui.exe
<sha256>  README.md
<sha256>  LICENSE
<sha256>  SECURITY-OVERVIEW.md
<sha256>  BUILD-INFO.txt
```

The SHA256 of the zip archive itself is recorded separately after the package
is assembled (not included inside the zip).

Hash format: lowercase hex, two spaces before filename, one file per line.

PowerShell generation example:
```powershell
Get-FileHash disk-insight-ui.exe -Algorithm SHA256 |
  ForEach-Object { "$($_.Hash.ToLower())  disk-insight-ui.exe" }
```

## 7. Pre-build checks

Run before building the release candidate:

```powershell
git status
git log --oneline -5
npm run build
npm run tauri build
```

Confirm:
- Working tree is clean
- Version is `0.6.0` in `package.json`, `tauri.conf.json`, and `Cargo.toml`
- TypeScript build passes without errors
- Tauri release build completes successfully
- Release exe starts without a console window
- `windows_subsystem = "windows"` is present in `src-tauri\src\main.rs`
- `TREE_FOCUS_DEBUG`, `PERF_LOG`, `PERF_TREE` are all `false`
- Company-safe UI is not present in the release build
- Load demo button is visible and loads public-safe demo data
- README screenshot paths resolve to the correct images

## 8. Manual package procedure (candidate)

The script below is a candidate for `scripts/build-release-package.ps1`,
to be implemented in v0.6.0-J. Do not run this in v0.6.0-I.

```powershell
$version = "0.6.0"
$out = "dist-release\disk-insight-v$version-windows-x64"

Remove-Item -Recurse -Force $out -ErrorAction SilentlyContinue
New-Item -ItemType Directory -Force $out | Out-Null

Copy-Item src-tauri\target\release\disk-insight-ui.exe $out\
Copy-Item README.md $out\
Copy-Item LICENSE $out\
Copy-Item docs\security-overview.md "$out\SECURITY-OVERVIEW.md"

# Generate BUILD-INFO.txt
$commit      = git rev-parse HEAD
$commitShort = git rev-parse --short HEAD
$branch      = git rev-parse --abbrev-ref HEAD
$buildTime   = Get-Date -Format "yyyy-MM-dd HH:mm:ss"
@"
Project           : disk-insight
Version           : $version
Commit            : $commit
Commit short      : $commitShort
Branch            : $branch
Build time        : $buildTime
Signed            : NO
GitHub Release    : NO
Safety model      : Normal + Advanced
Company-safe UI   : removed in v0.5.18-C
Network           : none
Telemetry         : none
Updater           : none
TREE_FOCUS_DEBUG  : false
PERF_LOG          : false
PERF_TREE         : false
"@ | Out-File -Encoding utf8 "$out\BUILD-INFO.txt"

# Generate SHA256SUMS.txt
$files = @("disk-insight-ui.exe","README.md","LICENSE","SECURITY-OVERVIEW.md","BUILD-INFO.txt")
$sums = $files | ForEach-Object {
    $h = (Get-FileHash "$out\$_" -Algorithm SHA256).Hash.ToLower()
    "$h  $_"
}
$sums | Out-File -Encoding utf8 "$out\SHA256SUMS.txt"

# Create zip
Compress-Archive -Path $out -DestinationPath "dist-release\disk-insight-v$version-windows-x64.zip" -Force

Write-Host "Package: dist-release\disk-insight-v$version-windows-x64.zip"
```

## 9. Checks before considering a GitHub Release

All of the following must be confirmed before any GitHub Release is published.

### Documentation
- [ ] README matches current implemented features
- [ ] Screenshots are public-safe (demo data, no real user paths)
- [ ] Safety model section is accurate
- [ ] Known limitations are complete and accurate
- [ ] LICENSE file is present (`LICENSE`, MIT)
- [ ] No "safe to delete" or similar forbidden wording anywhere
- [ ] SECURITY-OVERVIEW matches current behavior

### Code / build
- [ ] Version is `0.6.0` across `package.json`, `tauri.conf.json`, `Cargo.toml`
- [ ] `TREE_FOCUS_DEBUG`, `PERF_LOG`, `PERF_TREE` are all `false`
- [ ] `windows_subsystem = "windows"` present (no console window on launch)
- [ ] Company-safe UI is not present in release build
- [ ] Load demo loads public-safe data with no real paths
- [ ] Build is reproducible from a clean state
- [ ] SHA256 generated and recorded

### Safety / content
- [ ] No real usernames / company names / internal paths in screenshots
- [ ] No real paths in embedded sample JSON
- [ ] Advanced Mode starts OFF on every launch
- [ ] Move to Recycle Bin is hidden until Advanced Mode is explicitly enabled
- [ ] No forbidden phrases in any public-facing document

### Release artifact
- [ ] Package extracts to a single root folder
- [ ] Exe runs after extraction without additional dependencies
- [ ] Package size is reasonable
- [ ] SHA256SUMS.txt is included and correct
- [ ] ZIP SHA256 is recorded separately

### Dogfooding
- [ ] Tested on the target machine (company PC or equivalent)
- [ ] No obvious regressions found
- [ ] Load demo → all demo views work as expected
