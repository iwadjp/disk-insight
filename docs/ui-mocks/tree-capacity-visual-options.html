確認ポイント ユーザーへの確認事項 — 次の実装前に
  1. どの案が最も「一目で容量を食っている場所が分かる」か？
    案 B (bar列), 案 C (text強調), 案 D (bar強化) から選ぶ場合、どれが直感的か。
  2. シンプルさを壊していないのはどれか？
    案 A と比較して、どこまで変化を受け入れられるか。
  3. TreeView だけに入れるか、Largest/Top/Search にも同じ表現を入れるか？
    画面全体で一貫させるなら、案 B や案 C が展開しやすい。 TreeView だけでよいなら、案 D も候補。
  4. 閾値強調が必要か、全行バー表示でよいか？
    案 B/D は全行に効果あり（閾値なし）。 案 C/E は閾値以上の行だけ変わる。 閾値 UI（Off / ≥1% / ≥3% / ≥5% / ≥10%）は必要か。
  5. % のみでよいか、絶対サイズ条件も必要か？
    ≥5% のみ、または ≥5% OR ≥10GB のような複合条件。 初期実装では % のみで十分か。
