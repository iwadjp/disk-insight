### 1.2 Screenshot safety rules

**Never include in any public screenshot:**

| Category | Examples |
|----------|---------|
| Company names | employer name, client name |
| Personal names | Windows username, full name |
| Internal project names | repo names, internal product names |
| Internal server / network paths | UNC paths, server hostnames |
| IP addresses | internal network ranges |
| License keys / tokens | any secrets in file paths |
| Real business data files | contract names, financial file names |

**Recommended safe content:**

- Generic test folder names: `demo-app`, `test-project`, `sample-data`
- Public tool cache paths: `node_modules`, browser cache (no real user home)
- Shallow drive roots: `D:\Samples\`, `C:\sample-disk\`
- Generic VM or archive names: `old-test-vm.vhd`, `archive-2023.zip`

**Before capturing:**
- Close all other windows or use a minimal taskbar
- Ensure no notifications or user-identifying UI elements are visible
- Use a clean-state launch (no scan results from a real drive if possible)

## 2. Release notes draft

```markdown
# disk-insight v0.6.0

## Status

Pre-release. This is the first public-readiness candidate.
No official stable release has been published yet.
This release is intended for local use and early feedback, not production deployment.

## Highlights

- TreeView-first disk usage navigation with lazy folder expansion
- Occupancy bar column for at-a-glance size comparison
- Top-N large file scan via direct NTFS MFT read
- View selector: All / Large review / Reviewable areas / Caution areas
- Persistent bookmarks (jump to folder across sessions)
- Session-only Review list with batch Copy paths / Copy quoted
- Explorer handoff: Show in Explorer, Select file, Show properties
- Insights panel: largest items under selected folder, subtree search
- Drive auto-detection
- Size metric selector: Current allocation / WOF-adjusted (experimental)
- Scan progress indicator with phase labels
- Normal + Advanced two-layer safety model
- Advanced Mode gated Move to Recycle Bin (explicit opt-in, session-only)

## Safety model summary

- Normal Mode (default): no destructive file operation is shown or available
- Advanced Mode: explicit session-only opt-in; resets to OFF on every launch
- Move to Recycle Bin requires per-item confirmation (path, size, risk warning shown)
- Move to Recycle Bin is not permanent deletion — items remain in Recycle Bin
  until the bin is manually emptied
- Delete / Rename / Cut / Paste are not implemented

## Privacy and network

- No network communication
- No telemetry or analytics
- No auto-updater
- Writes only to `%LOCALAPPDATA%\disk-insight\` (scan cache and bookmarks)

## Known limitations

- Pre-release; not a stable production release
- Unsigned binary — may trigger SmartScreen on first launch
- NTFS-focused; other file systems are not the current focus
- Cleanup classification is path-based heuristic only
- No multi-select file operations
- No full Windows Explorer shell context menu
- No dark mode

## Requirements

- Windows 10 or later
- Administrator privileges recommended for full MFT scan access

## Installation

Unzip the release archive and run `disk-insight-ui.exe` as Administrator
for full scan access.

## Checksums

See `SHA256SUMS.txt` in the release archive.
```

## 7. Demo data (v0.6.0-G)

### Overview

Public screenshots must use demo data, not real scan results.
Real scan results may contain usernames, company paths, or private project names.

### Demo data location

```
public/sample/probe7.sample.json
```

This file is embedded in the Tauri binary at build time and served as the
sample / demo dataset. It replaces the previous real-scan snapshot with
fully public-safe synthetic paths.

### Demo data paths

All paths use the prefix `C:\` with generic, non-identifying names:

```
C:\Projects\demo-app\node_modules   (Dev dependency, 2.5 GB)
C:\Projects\photo-tool\target       (Dev dependency, 1.8 GB)
C:\Users\demo\AppData\Local\Browser\Cache  (Cache candidate, 1.2 GB)
C:\Temp                             (Temp candidate, 3 GB)
C:\$Recycle.Bin                     (Recycle Bin, 1.5 GB)
C:\VMs\old-test-vm                  (large VM folder, 85 GB)
C:\Windows                          (Caution: Protected system)
C:\Program Files                    (Caution: App-managed)
```

No real usernames, company names, project names, or private paths are included.
The username `demo` is used in place of any real Windows username.

### How to load demo data for screenshots

1. Build or run the app: `npm run tauri dev` or `npm run tauri build`
2. Click "Load demo" in the toolbar
3. Demo data is now displayed — safe to screenshot

The "Load demo" button is visible in both dev and release Tauri builds.
It is not visible in a plain browser context (production web build).

### What to expect in demo data

| View | Content |
|------|---------|
| Main TreeView | Root children: VMs, Users, Projects, Windows, Program Files, etc. |
| Large review | 5 candidates: node_modules, target, Browser\Cache, Temp, $Recycle.Bin |
| Reviewable areas | VMs, Users, Projects, Temp, $Recycle.Bin (loaded root rows ≥ 1 GiB, not caution) |
| Caution areas | Windows, System Volume Information, Program Files, Program Files (x86), ProgramData |
