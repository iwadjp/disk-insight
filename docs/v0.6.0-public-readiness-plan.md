## 2. Product Positioning

### Candidate description

```
A fast, local-only Windows disk usage viewer inspired by WizTree workflows.
```

Alternative:

```
A local-first disk usage viewer focused on fast scanning, TreeView-first
navigation, and cautious cleanup assistance.
```

### Framing principles

- Do NOT call it a "WizTree clone." Functionality overlaps, goals differ.
- Do NOT call it a "safe cleanup tool" or say "delete safely."
- Do NOT use language implying automatic cleanup or AI-driven deletion.
- Emphasize: local-only / no telemetry / no network / no auto-update.
- Emphasize: Normal Mode is a viewer; destructive ops are Advanced-only.
- The cleanup classification (Large review / Reviewable areas / Caution areas)
  is a path heuristic -- label it as such in documentation.

## 3. Public Release Principles

Before publishing to GitHub:

1. Dogfood it long enough to trust it for personal disk management.
2. Normal Mode must be a safe viewer with no destructive operations shown.
3. Advanced Mode must remain explicit opt-in, session-only, non-persistent.
4. All destructive operations (Move to Recycle Bin) must be gated behind
   Advanced Mode with per-item confirmation.
5. No telemetry, no updater, no network communication.
6. README must accurately describe safety posture.
7. Screenshots must be public-safe (no personal/company paths).
8. Build must be reproducible from source.
9. Unsigned build status must be clearly stated in README and release notes.
10. Company PC usage is each user's responsibility per their environment policy.
    Document the guidance; do not make claims about what is "allowed."

## 8. Security / Safety Checklist

Verify before each public release:

```
[ Network ]
  [ ] No HTTP/socket client code
  [ ] No reqwest / hyper / updater dependency in Cargo.toml
  [ ] No devUrl in release bundle (tauri.conf.json check)

[ Telemetry ]
  [ ] No analytics, no crash reporting, no event logging to external service

[ Destructive operations ]
  [ ] Move to Recycle Bin: only shown when Advanced Mode is ON
  [ ] Advanced Mode: requires explicit acknowledgement
  [ ] Advanced Mode: session-only, resets on launch
  [ ] Recycle confirmation modal shows path, size, risk warning
  [ ] Protected/app-managed path warning triggers correctly
  [ ] Delete / Cut / Rename / Paste: NOT implemented (verify grep)

[ Data handling ]
  [ ] Review list: session-only, not persisted to disk
  [ ] Bookmarks: persisted to %LOCALAPPDATA%\disk-insight\bookmarks.json only
  [ ] Cache: %LOCALAPPDATA%\disk-insight\cache\ only
  [ ] No other write paths

[ Background process ]
  [ ] No background thread scanning or polling after scan completes
  [ ] No auto-start on login

[ Wording ]
  [ ] No "safe to delete" / "delete safely" / "unnecessary files" language
      in UI or README
  [ ] Classification labels are described as path heuristics in docs
```

## 9. Known Limitations

For README and release notes:

```
- NTFS-focused: optimized for NTFS volumes. exFAT/FAT32 support is limited.
- Admin requirement: MFT scanning requires administrator privilege.
  Non-admin mode starts with a prompt; some features are restricted.
- Unsigned binary: triggers SmartScreen on first run. User must confirm.
  Code signing is planned but not yet implemented.
- Cleanup classification is path heuristic: Large review / Reviewable areas /
  Caution areas are based on file/folder path patterns.
  They do NOT indicate that a file is safe to delete.
  User judgment is required for all cleanup decisions.
- Large review is top-N scan results: shows the largest items from the scan;
  may not reflect all files if scan is partial.
- Reviewable / Caution areas use loaded rows: filtered from the in-memory
  tree; may not include items not yet loaded (lazy tree).
- No move-to-folder: file moves are not implemented.
- No multi-select file operation: single-item recycle only (Advanced Mode).
- No shell-equivalent context menu: right-click shows app-defined options,
  not Windows shell context menu.
- No GitHub release yet: current builds are local dogfooding artifacts.
- Dark mode: not implemented in current release.
```
